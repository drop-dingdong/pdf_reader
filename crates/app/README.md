# app —— 桌面壳（egui/eframe）

```bash
# 1) 准备 PDFium 动态库（只需一次）
scripts/fetch-pdfium.sh

# 2) 运行
cargo run -p app -- /path/to/file.pdf     # 命令行打开
cargo run -p app                          # 启动后把 PDF 拖进窗口
```

## 模块划分

| 模块 | 内容 | 怎么验证 |
| --- | --- | --- |
| `view.rs` | 坐标换算、输入映射、纹理存储 | `cargo test -p app`（7 个用例，纯逻辑，不需要窗口） |
| `app.rs` | egui 胶水：面板、画布、交互 | **需要真实窗口 → 交给你人工验收**（见下） |

## 人工验收清单（按 agent.md 规则 2）

> 逐项看"应该看到什么"。任何一项不符，请把现象（最好带截图/录屏）反馈给我。

| # | 操作 | 预期 |
| --- | --- | --- |
| 1 | `cargo run -p app -- <文件>` | 窗口出现，第一页显示在左上，状态栏显示"第 1 / N 页"与缩放比例 |
| 2 | 滚轮下滑/上滑，**特别留意翻页边界** | 页面连续滚动、跟手；新页进入视口时**不应有明显卡顿**（预取 ±2 页 + 每帧限量上传纹理，D-14） |
| 3 | 把某个词滚到屏幕中央 → `Ctrl` + 滚轮（或触控板捏合） | 页面缩放，且该词**仍在屏幕中央附近**（D-05；Ctrl+滚轮的映射见 D-10） |
| 4 | `Ctrl`+`+` / `-` / `0` | 只缩放**文档**，界面本身不再跟着放大（D-10） |
| 5 | 连续快速缩放（按住 Ctrl 连滚多格） | 新比例渲染完成前应显示**上一档缩放的画面**（拉伸），不应出现大片白色填充（D-12） |
| 6 | 连续缩小到页面明显小于窗口 | 页面应**在窗口中居中**（水平与垂直都有留白），而不是贴在左上角（D-09） |
| 7 | 工具栏"拖拽：平移 / 选字"两档 | 「平移」拖动只移动画面（默认）；「选字」只能选文字；按住 `Shift` 拖动**临时反选**当前工具（D-13，"自动"模式已移除） |
| 8 | 打开带 `/Rotate` 的 PDF（横向页） | 页面按**显示方向**渲染：文字正立、宽高正确（不是横躺或被再旋转一次） |
| 9 | 拖选文字 → `Ctrl+C`（或点工具栏"复制"） | 出现半透明蓝色高亮；复制后粘贴得到选中文本（跨页以换行连接）。状态栏显示"已复制 N 个字符"。**`Ctrl+C` 现已可用**（egui 把 Ctrl+C 报成 `Event::Copy`） |
| 10 | 双击一个词 | 选中整词（**三击选行已按第三轮验收移除**，见 [docs/backlog.md](../../docs/backlog.md)） |
| 11 | 工具栏输入关键词回车 | 状态栏显示命中数，**命中位置居中**（D-11）；黄色=全部命中、橙色=当前命中；**"上一个" / "下一个"** 可循环 |
| 12 | 点击左侧"目录"中的条目 | 跳到对应页，且该页**顶部恰好对齐窗口顶部**（D-11） |
| 13 | 上一页 / 下一页按钮 | 同上：目标页**顶部对齐**（不再把整页居中） |
| 14 | 工具栏"跳到：[页码] 回车" | 跳到指定页；越界或非数字会给出提示；输入框会跟随当前页自动更新 |
| 15 | 打开**加密** PDF | 弹出模态密码框；输错提示"密码错误，请重试"（不崩溃）；输对正常打开 |
| 16 | 拖动侧栏与画布之间的**分隔条**（5px，悬停变左右箭头光标） | 宽度跟手变化（160–640），松手保持 —— **不再使用 egui 内建拖拽**：它把状态存在"父 Ui 的 id"下，而 eframe 每帧给新的根 Ui，读不回来（D-20） |
| 17 | 让多页同时可见（例如 4/5/6 页）后缩放 | **每一页行为一致**：都先显示旧内容再变清晰，不会只有非中心页闪白（D-19：旧代码在缩放时丢掉了非当前页的纹理）|
| 18 | 把 PDF 文件拖进窗口（**含刚启动、尚未打开任何文档时**） | 打开该文件（首轮验收曾报"拖进去没反应"，已修） |
| 19 | （可选）打开几百页的 PDF 快速滚动 | 长时间保持响应，不卡死 |
| 20 | （可选）放大到 **800%** 看大页 | 画面应正常显示；内存不应暴涨（超过 **4 MP** 才分块，瓦片只渲染视口内那几块）|
| 21 | 点击页面上的链接 | 跳转到目标页：**有具体坐标（/XYZ）时把该坐标放到视口中心**；只有页（/Fit 等）时顶部对齐（D-24）。外部 URL 只在状态栏提示（打开浏览器未实现）|
| 22 | 勾选工具栏「链接框」（默认关闭），缩放到 **75% 以上** | 页面上出现**红色空心方框**标出链接热区；缩放到 75% 以下时**不再显示**（阈值 `LINK_OVERLAY_MIN_ZOOM`，可调）|
| 23 | 点工具栏「添加测试浮窗」多次 | 视图内出现浮窗，**后添加的在更上层**；可拖标题栏移动、拖右下角改大小、点右上角 ✕ 关闭；**拖到视图外会被拉回区内**（D-36）|
| 24 | 勾选「引用点」（默认关闭），缩放到 75% 以上 | 每个**被链接指向的具体坐标**处出现圆圈标记；同一位置多个链接只标一次；缩放到 75% 以下不显示（D-37）|
| 25 | 点工具栏「截图」，拖动框选，按 **Enter** | 主视图蒙半透明亮灰、框内透明；期间拖动/滚轮/缩放/链接跳转都不生效，但瓦片**继续加载**；浮窗与链接框/引用点都隐藏；终端输出 `[截图] 视图区域 (x,y w×h) | 页 n 页空间 (…)` （D-38）|
| 26 | 截图模式下框选后按 **Enter** | 选区被做成快照并**放进一个新浮窗**（标题「截图 #n」）；浮窗可移动/改大小/关闭，图片按原长宽比居中显示，**改大小不改变内容**；终端仍打印一行 `[截图] …` 供调试 |
| 27 | 按 Enter 后缩放/滚动/换页，再看该浮窗 | 内容**保持不变**（快照自包含，不依赖主视图纹理）|
| 28 | 勾选「引用点」，**点击某个圆圈标识** | 进入截图模式，选区**初值为该点已存的矩形**；拖动可调整，**Enter** 保存（只存与当前页重叠的部分）并用新浮窗显示截图，**Esc** 取消不改动（D-42）|
| 29 | 截图模式进行中再点「截图」按钮 | 按钮**置灰无响应**，直到 Esc/Enter 回到正常阅读模式（截图不可相互覆盖）|
| 30 | 把鼠标移到**页内链接**（带具体跳转坐标）上 | 出现**临时浮窗**显示该链接目标的引用点截图；首次会**当场渲染一次**，之后直接复用；指针移到该浮窗上也继续存在，离开两者后消失（D-43）|
| 31 | **点击**该临时浮窗 | 转为**永久浮窗**（同样的图），不再受鼠标位置影响；可移动/改大小/关闭 |
| 32 | 点击页内链接 | 跳到**该链接的被引用点矩形中心**（不是原始 `/XYZ` 坐标）；仅 `/Fit` 这类没有登记被引用点的目标仍按原语义（顶部对齐）|
| 33 | 鼠标从链接框移向临时预览浮窗 | 浮窗**左上角就在链接框中心**，两者必然重叠，因此移动过程中预览不会消失 |
| 34 | 滚轮滚动或拖动，同时鼠标经过页内链接 | **不出现**悬停预览；停止滚动约 250ms 后才恢复（D-45）|
| 35 | 让某个链接位于浮窗之下，把鼠标移到浮窗上（浮窗范围内）| **没有**悬停预览；点击也不跳转（浮窗屏蔽主视图动作）|
| 36 | 悬停某链接 → 点击预览浮窗固定 → 鼠标移开 → **再次悬停同一链接** | **不再弹临时预览**；那个已固定的浮窗**高亮**（橙色加粗边框 + 暖色标题栏）并**置顶**，鼠标移开后恢复常态（D-46）|
| 37 | 悬停**另一个**目的地不同的链接 | 仍正常弹临时预览（与已固定浮窗互不影响）|
| 38 | 点击某个固定浮窗的主体（不点关闭按钮）| 该浮窗**置顶**；**其它浮窗的相对层次不变**；点关闭按钮只会关闭、不触发置顶（D-47）|
| 39 | 悬停链接使临时预览出现（与某固定浮窗重叠）| 临时预览**压在固定浮窗之上**（最上层），点击它仍可固定（D-47）|
| 40 | 点击浮窗**标题栏**（不拖动）| 该浮窗**置顶**（与点击主体等价）；拖动标题栏则移动浮窗（D-48）|
| 41 | 在浮窗的**文字区/截图区**内按住拖动 | **移动浮窗**；PDF 页面**不会**跟着拖动（浮窗屏蔽内层拖拽）|
| 42 | 在**临时预览浮窗**内按住拖动 | 它被**固定**为永久浮窗，并带上拖动位移（等价于点击固定）|
| 43 | 截图模式下按 **Esc** | 静默退出，无输出 |
| 27 | 环境变量 `PDF_READER_DIAGNOSE=1` 启动后缩放 | stderr 每秒打印一行诊断（缩放/视口/可见页/每页画法/瓦片就绪数/`max_texture_side`）——**排查"看不到内容"时请把这几行发我** |

## 已知限制（非缺陷，已排期）

* **没有原生文件对话框**：目前用命令行参数或拖放打开；`rfd` 留待 M2。
* **中文界面依赖系统字体**（`system_fonts` 特性）；若系统无 CJK 字体会显示成方块，可反馈后改为内置字体。
* 文本的字号/样式尚未提取（`TextSpan`），因此界面不做字体差异渲染；**选中与高亮不受影响**。
* 剪贴板走 egui 自身实现：`Ctrl+C` 在窗口内有效。
* 搜索是同步接口（D-03）：超大文档搜索时窗口会短暂无响应，属已知取舍。
* 排查显示类问题：用 `PDF_READER_DIAGNOSE=1` 启动，stderr 每秒打印一行诊断（缩放/视口/可见页/每页画法/瓦片就绪数/`max_texture_side`）。
  其中「画法」取值：`整页纹理` / `旧图拉伸` / `旧瓦片预览` / `瓦片 n/m` / `白底页框`；排查「看不到内容」时看这一项即可定位（第四轮就是靠它一击命中瓦片位置算错）。
