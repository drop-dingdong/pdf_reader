# app —— 桌面壳（egui/eframe）

```bash
# 1) 准备 PDFium 动态库（只需一次）
scripts/fetch-pdfium.sh

# 2) 运行
cargo run -p app -- /path/to/file.pdf     # 命令行打开
cargo run -p app                          # 启动后把 PDF 拖进窗口
```

## 模块划分

| 模块 | 内容 | 怎么验证 |
| --- | --- | --- |
| `view.rs` | 坐标换算、输入映射、纹理存储 | `cargo test -p app`（7 个用例，纯逻辑，不需要窗口） |
| `app.rs` | egui 胶水：面板、画布、交互 | **需要真实窗口 → 交给你人工验收**（见下） |

## 人工验收清单（按 agent.md 规则 2）

> 逐项看"应该看到什么"。任何一项不符，请把现象（最好带截图/录屏）反馈给我。

| # | 操作 | 预期 |
| --- | --- | --- |
| 1 | `cargo run -p app -- <文件>` | 窗口出现，第一页显示在左上，状态栏显示"第 1 / N 页"与缩放比例 |
| 2 | 滚轮下滑/上滑，**特别留意翻页边界** | 页面连续滚动、跟手；新页进入视口时**不应有明显卡顿**（预取 ±2 页 + 每帧限量上传纹理，D-14） |
| 3 | 把某个词滚到屏幕中央 → `Ctrl` + 滚轮（或触控板捏合） | 页面缩放，且该词**仍在屏幕中央附近**（D-05；Ctrl+滚轮的映射见 D-10） |
| 4 | `Ctrl`+`+` / `-` / `0` | 只缩放**文档**，界面本身不再跟着放大（D-10） |
| 5 | 连续快速缩放（按住 Ctrl 连滚多格） | 新比例渲染完成前应显示**上一档缩放的画面**（拉伸），不应出现大片白色填充（D-12） |
| 6 | 连续缩小到页面明显小于窗口 | 页面应**在窗口中居中**（水平与垂直都有留白），而不是贴在左上角（D-09） |
| 7 | 工具栏"拖拽：平移 / 选字"两档 | 「平移」拖动只移动画面（默认）；「选字」只能选文字；按住 `Shift` 拖动**临时反选**当前工具（D-13，"自动"模式已移除） |
| 8 | 打开带 `/Rotate` 的 PDF（横向页） | 页面按**显示方向**渲染：文字正立、宽高正确（不是横躺或被再旋转一次） |
| 9 | 拖选文字 → `Ctrl+C`（或点工具栏"复制"） | 出现半透明蓝色高亮；复制后粘贴得到选中文本（跨页以换行连接）。状态栏显示"已复制 N 个字符"。**`Ctrl+C` 现已可用**（egui 把 Ctrl+C 报成 `Event::Copy`） |
| 10 | 双击一个词 | 选中整词（**三击选行已按第三轮验收移除**，见 [docs/backlog.md](../../docs/backlog.md)） |
| 11 | 工具栏输入关键词回车 | 状态栏显示命中数，**命中位置居中**（D-11）；黄色=全部命中、橙色=当前命中；**"上一个" / "下一个"** 可循环 |
| 12 | 点击左侧"目录"中的条目 | 跳到对应页，且该页**顶部恰好对齐窗口顶部**（D-11） |
| 13 | 上一页 / 下一页按钮 | 同上：目标页**顶部对齐**（不再把整页居中） |
| 14 | 工具栏"跳到：[页码] 回车" | 跳到指定页；越界或非数字会给出提示；输入框会跟随当前页自动更新 |
| 15 | 打开**加密** PDF | 弹出模态密码框；输错提示"密码错误，请重试"（不崩溃）；输对正常打开 |
| 16 | 把 PDF 文件拖进窗口（**含刚启动、尚未打开任何文档时**） | 打开该文件（首轮验收曾报"拖进去没反应"，已修） |
| 17 | （可选）打开几百页的 PDF 快速滚动 | 长时间保持响应，不卡死 |
| 18 | （可选）放大到 **800%** 看大页 | 画面应正常显示；内存不应暴涨（超过 **4 MP** 才分块，瓦片只渲染视口内那几块）|
| 19 | 环境变量 `PDF_READER_DIAGNOSE=1` 启动后缩放 | stderr 每秒打印一行诊断（缩放/视口/可见页/每页画法/瓦片就绪数/`max_texture_side`）——**排查"看不到内容"时请把这几行发我** |

## 已知限制（非缺陷，已排期）

* **没有原生文件对话框**：目前用命令行参数或拖放打开；`rfd` 留待 M2。
* **中文界面依赖系统字体**（`system_fonts` 特性）；若系统无 CJK 字体会显示成方块，可反馈后改为内置字体。
* 文本的字号/样式尚未提取（`TextSpan`），因此界面不做字体差异渲染；**选中与高亮不受影响**。
* 剪贴板走 egui 自身实现：`Ctrl+C` 在窗口内有效。
* 搜索是同步接口（D-03）：超大文档搜索时窗口会短暂无响应，属已知取舍。
* 排查显示类问题：用 `PDF_READER_DIAGNOSE=1` 启动，stderr 每秒打印一行诊断（缩放/视口/可见页/每页画法/瓦片就绪数/`max_texture_side`）。
  其中「画法」取值：`整页纹理` / `旧图拉伸` / `旧瓦片预览` / `瓦片 n/m` / `白底页框`；排查「看不到内容」时看这一项即可定位（第四轮就是靠它一击命中瓦片位置算错）。

## 与设计文档的对应

* 坐标系换算链：`PagePlacement::page_to_content` / `rect_to_content`（PDF 页面空间 → 内容空间），
  再减去 `Viewport::scroll` 得到屏幕位置 —— 见 [data-flow.md 场景 6](../../docs/data-flow.md)。
* 白底页框占位：decision-log **D-06**；缩放锚点：**D-05**；分块渲染：**D-02**。
