## 场景与现象（用户描述）

> "视图中从上到下排列着第 4/5/6 页，5 页位于视野中心。缩放比例改变时，
> **中间页没有突然变白**，但 4/6 页却会突然变白后重新出现图像。"

这个描述非常精确，直接指向了根因。

## 根因（D-19）：我在布局变化时把"非当前页"的纹理全丢了

```rust
// apply_and_pump() 里处理 SessionEvent::LayoutChanged 的旧代码（错）
self.textures.retain(|key| key.page == current);
```

每次缩放/旋转都会触发 `LayoutChanged`，于是：

* **中心页**（= 当前页）：旧比例的纹理被保留 → 有旧图可拉伸 → **不闪白**；
* **第 4/6 页**：纹理被全部丢弃 → 找不到旧图 → 先画白纸，等新比例渲染完再出现 **→ 闪白**。

正是用户看到的"只闪非中心页"。这条 `retain` 是第二轮为"省显存"写的，
在当时（还没有缩放过场预览）无害，但第三轮加入"用旧图顶替"之后就变成了缺陷。

## 修复

1. **删掉那条 `retain`**，改为有界策略 `KeyedStore::retain_preview_scales()`（D-19）：
   保留**可见页 ±1 + 当前页**，且每页保留「**当前比例 + 最接近它的一个旧比例**」（旋转必须匹配）。
   * 不能全丢：否则就是这次的闪白；
   * 不能全留：一次连续缩放会产生十几档比例，显存会无限增长。
2. **绘制优先级**统一为"绝不给空白让路"：
   当前比例真瓦片 → 上一档**整页图**拉伸 → 上一档**瓦片**按比例拼回整页 → 白纸。
   注意第 3 档现在**不再依赖"是否处于缩放预览窗口"**，因此预览窗口过期后、
   新瓦片还没到齐的那几帧也不会闪白。
3. 诊断行新增 `预览中=` 字段，便于再次核查。

## 侧栏宽度依旧改不动（D-20）

前两轮的做法都失败了：

* 第二轮：`resizable(true)` + 每帧把观察到的宽度回填成 `default_size`
  —— 无效，因为面板状态以 `parent_ui.scope_id().with_salt(id)` 为键持久化，
  而 eframe 每帧传入的是**新的根 `Ui`**（id 每帧都不同），拖拽结果写进去、下一帧读不回来。

**这次换掉依赖**：宽度由 app 自己持有（`sidebar_width`），

* `Panel::left("outline").resizable(false).exact_size(width)` —— 面板只负责"摆"，不负责"拖"；
* 在**画布左侧自绘一条 5px 拖拽条**（`Sense::drag()`）：悬停变 `ResizeHorizontal` 光标、
  按下拖动即改 `sidebar_width`（夹取在 160–640），下一帧 `exact_size` 立即生效。

这样完全不依赖 egui 的面板持久化，行为可预期。

## 补记：侧栏能拖了，但画布什么都没有（第五轮验收的第二个反馈）

> "侧栏分隔条现在运行良好，但没有图像显示。"

**这是我的新缺陷，且只可能由上一版改动引入**：

```rust
// 上一版（错）
let (strip_response, strip) = ui.allocate_painter(
    EVec2::new(SIDEBAR_HANDLE_WIDTH, ui.available_height()),   // 5px × 整高
    Sense::drag(),
);
```

`allocate_painter` 会**按布局流占用空间**：中央面板是纵向布局，这条"5px × 整高"的拖拽条
把整个高度都吃掉了，紧接着的 `ui.available_size()` 高度即为 0 ——
画布矩形高度 0，什么都画不出来。而拖拽条本身在左侧 5px 处工作正常，
所以现象正好是"分割线能拖，但没有图像"。

**修复**（D-21）：

* 拖拽条与画布都改用**显式矩形 + `Ui::interact`**，完全不参与布局流；
* 画布矩形由纯函数 `view::canvas_rect_for(full, handle_width)` 计算：
  从拖拽条右侧开始，**高度保持满高**，并在区域比拖拽条还窄时夹取避免负尺寸；
* 回归测试 `canvas_rect_keeps_full_height` 明确断言 `height == 800.0`（满高）——
  这正是当时的缺陷点；
* 顺带修掉 D-19 的一个隐患：纹理保留的旋转判定改为**按页取**
  （同一份文档里各页 `/Rotate` 可能不同，用当前页的旋转去筛会把别的页纹理误删）。
