# P7 注释管理面板设计

## 目标

把注释从“画布上碰运气点击”提升为可发现、可定位、可管理的列表。面板只读地展示
`AnnotationStore`，不新增持久化字段，也不引入 `.annot.json`。

## 已确认的交互

- 侧栏新增第三个标签页「注释」；
- 按页分组，行内显示类型 + 正文首行摘要；
- 点击行：跳到对应页、打开该注释已有的正文浮窗，并给注释画短暂的中性轮廓；
- 悬停行：tooltip 显示正文前面一段，不打开浮窗、不改变数据；
- 正文行按可用宽度截断，不按固定字符数；无正文显示「无正文」；
- 只读的外部内联注释显示「只读」标记；
- 顶部筛选：类型（高亮/下划线/删除线/墨迹）、仅外部、仅只读；
- 不做持久选中态，不新增“注释摘要”字段。

## 为什么点击后还要轮廓

注释本身可能是多种颜色；再改颜色会破坏颜色语义。使用白色/黑色双描边或短暂外框，
只表示“当前定位到这一条”，不修改注释属性。

## 正文显示

1. 列表行：第一行 + 宽度截断；
2. 悬停：约 200–300 字的 tooltip；
3. 点击：打开现有 `FloatOwner::Annotation` 正文浮窗，完整查看/编辑。

不复用「自定义文本 preview」：那是独立数据对象，和注释正文不是同一份数据。

## 颜色修改入口

画布注释与列表行统一使用 `annotation_context_menu`：颜色 + 删除。
已写入 PDF 的自有注释改色采用“旧对象删除 + 新对象重建”，撤销/重做整体切换；
外部注释暂不改色，避免改变归属。删除按钮在列表每行常驻，右键菜单保留。

## 外部/自有标记

不按颜色区分归属。只对无对象号、不能写回的内联外部注释显示小「只读」标记；
外部/自有可在 tooltip 或筛选中体现。归属不是主要信息，能力才是。

## 文本 fit（暂不实现）

按**当前页**文本 bbox 做“适合文本/裁边”视图是可行的独立功能；
不要用全 PDF 最大文本矩形（会被封面、折页、页脚带偏）。
它不能替代下划线/删除线的基线问题；基线应使用 `TextChar.origin.y`。

## 墨迹优先级

1. 已有注释改颜色（必要，允许对象重写）；
2. 墨迹平滑/抽稀（必要，成本低）；
3. 多笔画合并、压感、橡皮擦（暂不必要；当前“一笔 = 一条注释 = 一次撤销”
   语义简单，合并会复杂化撤销与 PDF 结构）。

## 非目标

- 不引入设置缓存/阅读进度文件（需单独调研）；
- 不改变注释写回模型；
- 不在本阶段做跨文档注释搜索。
