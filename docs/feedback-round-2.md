## 2. ✅ 翻页边界处明显卡顿

**根因**：两件事都发生在"新页刚进入视口"那一刻 ——

1. 只预取 ±1 页，下一页往往**刚好在进入视口时**才开始渲染；
2. 纹理上传（BGRA→RGBA 转换 + GPU 上传，整页 4 MiB 量级）在同一帧内完成，一帧内传多页就掉帧。

**修复**（D-14）：
* 预取半径 **1 → 2**（`PREFETCH_PAGE_RADIUS`），提前把下一页渲染好；
* 纹理上传**每帧限量 ≤ 2 张**（`MAX_UPLOADS_PER_FRAME`），开销摊到多帧；
* 相邻页的纹理**提前上传**，于是"进入视口"时纹理已在显存里。

## 3. ✅ 连续缩放时出现大片白色填充

**诉求**："缓存上一个缩放比例的渲染结果，在未完成渲染期间使用旧结果显示。"

**修复**（D-12）：新增 `KeyedStore::best_page_texture(page, rotation, scale)` ——
按 `scale_milli` 找**最接近**的整页纹理，用它拉伸到当前页面矩形显示；
只有连旧图都没有时才退回白底页框（D-06 降级为最终兜底）。
旋转不同不参与顶替（否则画面会横躺）。

## 7. ✅ "自动"模式不正常 → 已移除

**根因**：`PageText::hit_test` 的退化逻辑是"最近的字符中心"，**没有距离上限** ——
点在页面任何空白处都会命中"全页离得最近的那个字"，于是"自动"模式永远判定为选字，无法平移。

**修复**（D-13）：
* 移除 `Tool::Auto`，只保留 **平移（默认）/ 选字** 两档；
* `hit_test` 加容差（字高的一半）：远离文字的空白不再命中（有测试）；
* 按住 `Shift` 拖动可**临时反选**当前工具，想顺手复制一句时不必切换工具。

## 9. ✅ 复制按钮可用，但 `Ctrl+C` 无反应

**根因**：egui 把 `Ctrl/Cmd+C` 翻译成 **`egui::Event::Copy`**，而不是 `Event::Key { key: C }`。
我只监听了键盘事件，所以那个快捷键根本没到我这里。

**修复**：识别 `Event::Copy` 并映射为 `CopySelection`（同时在它出现时跳过 `Key::C`，避免复制两次）。

## 12. ✅ 跳转语义统一（D-11）

| 场景 | 修复后的行为 |
| --- | --- |
| 上一页 / 下一页 / 目录书签 | **目标页顶部对齐视口顶部**（"页面最上部恰好完全出现"），横向居中 |

## 15. ✅ 缩放 800% 后视野变黑

**根因**：分块渲染的高倍路径里，我只遍历**已缓存**的瓦片来绘制；
未就绪的瓦片既没有贴图、也**没有画白底占位**，于是那些区域直接露出深色画布 —— 就是"全黑"。
（低倍时走整页路径，整页占位覆盖全页，所以看不到这个问题。）

**修复**：
* UI 与提交渲染共用**同一个**范围计算：新增 `DocumentSession::visible_tiles(page)`
  （`request_tiles` 改为复用它，UI 用它枚举**全部**应绘制的瓦片，缺哪块补哪块白底）；
* 只要有任一真瓦片就画瓦片，绝不让"上一档旧图"盖住已就绪内容；
* 另有一项防御：分块阈值按面积（16 MP）判断，整页纹理不会超过常见 GPU 上限，
  但即便超过，现在也会走分块路径而不是丢纹理。
