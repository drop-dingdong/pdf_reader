# 待办与"以后可能需要"清单

> 按用户要求建立（第三轮验收 §10：三击选行"去掉吧，或者加入以后可能需要实现的清单"）。
> 这里的条目**都是有意推迟的**，不是遗忘的缺陷。做之前应先确认优先级。

## 已明确推迟（有明确触发条件）

| 条目 | 现状 | 触发/前置 |
| --- | --- | --- |
| **三击选行** | 第三轮验收决定移除 UI 入口 | 后端已就绪：`SelectionGranularity::Line` + `PageText::line_range_at()` 都有测试；只差画布接一个 `triple_clicked()` 分支（第二轮曾接过，但实测手感不佳，故撤回） |
| **加密 PDF 人工验收** | UI 模态密码框已实现，后端密码契约有自动化测试 | 需要你手上有一份加密 PDF |
| **扫描件搜索** | 0 命中时已提示"若为扫描件则没有文本层" | 需要一份扫描件样本；真正支持要上 OCR（明确超出 MVP） |
| **搜索命中"略偏上"** | 目前严格居中命中矩形 | 你反馈"居中"或"上方 1/3"哪个更顺手 |

## 体验类（按性价比排序）

| 条目 | 价值 | 代价 |
| --- | --- | --- |
| **截图可重渲染（高清截图）** | 记录选区为 `Vec<{页号, 该页内的 uv 矩形, 在总截图中的 uv 矩形}>`，缩放差异过大时按记录**重新渲染**以获得高清快照 | 用户已提出并同意之后再做；渲染压力较大，且正解依赖已搁置的"视口空间渲染" |

| ~~像素转换并行化~~（**已评估，不做**） | 把 BGRA→RGBA 转换放到工作线程，UI 线程只 `load_texture` | **用户决定不做**：跟手优先于瓦片视觉即时性，接受"拖动期间暂缓转换、松手补齐"（D-35）|
| **预渲染阶梯**（设计已通过，**实现已回滚**） | 手势期间画面**持续跟随**而不是冻结在旧图；新区域不再白纸 | 中等：上次实现因**策略反馈环**导致滚动/拖动不可用（见 [preview-ladder-design.md](preview-ladder-design.md) §10）。重做必须：仅手势边沿驱动、切档不取消在飞任务、请求层不做缓存判断、**默认关闭** |
| **视口空间渲染**（已评估，**暂不做**） | 把缩放从渲染参数里拿掉：HiDPI、质量阶梯、调用次数都随之自然 | **大**且有两处未解难题（用户提出，也是搁置理由）：①"内容对应的显示区域"在滚动中如何维护映射；②缩放时如何失效与重建。page-space + 瓦片模型正是绕开这两点才有现在的简单性。详见 [deep-zoom-design.md](deep-zoom-design.md) §2 |
| **屏幕空间瓦片预取**：按滚动方向优先预取前方瓦片 | 快速滚动更稳 | 小 |
| **HiDPI 清晰度** | 1 PDF 点 = 1 位图像素，在 1.5×/2× 显示器上会被 GPU 放大而略糊 | 小：把 `pixels_per_point` 乘进请求的 scale（缓存键不受影响）；需要确认各平台取值 |
| **页面坐标系归一化** | 热区/文本与渲染图**整体偏移**（例如整体差一行字高）：该页 `MediaBox` 原点非 0，或 `CropBox ≠ MediaBox` → 渲染按 CropBox、热区按 MediaBox。修法：后端读页面包围盒原点，把文本与热区坐标统一归一化到"渲染所用的盒子" | 小-中：仅后端适配层。**注意判据**：`越界` 只能发现大偏移，整体小偏移不会越界（用户指出）——更可靠的确认方式是看**文本选择高亮是否也同样偏移** |
| **打开外部链接** | 链接目标为 URI 时，目前只在状态栏提示 | 小：接一个平台打开方式（`open`/`xdg-open`/`ShellExecute`），但属平台能力，需要你确认要不要做 |
| **目录项也按落点居中** | 目前目录按 D-11 顶部对齐；若你希望"有落点就居中"与链接一致，是一行改动 | 小 |
| **缩略图侧边栏** | 长文档导航 | 小（复用渲染路径，`scale` 用很小的值） |
| **界面 UI 缩放入口** | D-10 关掉了 egui 内建的 `Ctrl`+`+` 缩放界面 | 小（设置页里放两个按钮） |

## 功能类（M2/M3 计划内）

| 条目 | 说明 |
| --- | --- |
| 原生文件对话框（`rfd`） | 目前只能命令行参数或拖放打开 |
| 最近文件 + 窗口尺寸/位置记忆 | `KeyValueStore` / `AppSettings` 两个 trait 已设计并实现（testkit 版），只差接线 |
| 搜索后台化 + 命中列表侧栏 | 现在搜索是同步的（D-03），超大文档会短暂无响应 |
| 对开/双页布局 | `PageLayout` 的新实现即可，接口无需改动（这正是当初把布局抽成 trait 的原因） |
| 文本字号/样式 | `TextSpan` 目前整页一段、字号为 0；选中与高亮不受影响 |
